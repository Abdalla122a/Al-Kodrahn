الكودرهن — إعادة بناء Python/Kivy

الملفات:
- main.py: التطبيق كاملاً.
- buildozer.spec: إعدادات بناء APK للأندرويد.
- requirements.txt: المكتبات المطلوبة.

المزايا:
- يعمل محلياً دون إنترنت بعد تثبيته.
- قاعدة بيانات SQLite تحفظ العمليات على الهاتف.
- الإجمالي الكلي = مجموع الوارد + مجموع المصروف (المصروف لا يخصم من الوارد).
- منع تكرار رقم العملية على مستوى كل السجل مع تحذير.
- أقسام وارد ومنصرف وإضافة أقسام وتعديلها.
- لوحة ألوان جاهزة: أحمر، أخضر، أزرق، بنفسجي، تركوازي، برتقالي، داكن.
- اختيار لون مخصص من عجلة الألوان وحفظه.
- عملة قابلة للتعديل.

بناء APK:
يفضل البناء على Linux أو WSL:
1) تثبيت Python وJava وBuildozer ومتطلبات Android SDK/NDK.
2) افتح الطرفية داخل مجلد المشروع.
3) نفذ: buildozer android debug
4) ستجد APK داخل مجلد bin.

ملاحظات:
- هذا مشروع Python/Kivy جديد وليس استعادة لكود APK السابق.
- لا أستطيع ضمان التحديث فوق APK القديم؛ يتطلب ذلك نفس package id وشهادة التوقيع القديمة.
- النسخة الحالية تحفظ البيانات في SQLite داخل مساحة التطبيق الخاصة.
- الواجهة مصممة كبداية عملية؛ قد تحتاج معاينة على جهاز أندرويد لضبط تشكيل ومحاذاة العربية حسب إصدار Kivy والخطوط.
